# Enemy Info Drawer Debug

Open `enemy_info_drawer_debug_scene.tscn` directly in Godot to inspect the attacked-enemy card without entering the application route.

The debug panel provides HP and shield sliders, one/two/three-digit random HP values, random target portraits, both attack-logo variants, and one-to-four attacker layouts. These controls are presentation-only and do not write to Session or battle data.
