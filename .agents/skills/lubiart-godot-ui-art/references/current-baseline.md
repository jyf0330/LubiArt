# LubiArt 当前执行基线

本文件是每轮快速恢复用的精简索引。详细项目规范以仓库根 `AGENTS.md` 为准；`conversation-synthesis.md` 保留标准演进、历史证据和逐轮审计，不再要求每轮全量加载。

## 每轮启动

1. 完整读取项目 Skill、仓库根 `AGENTS.md` 和本文件。
2. 用本轮需求关键词、相关文件路径、功能名和已知问题名检索 `conversation-synthesis.md`，读取所有命中条目的完整上下文；同时检查当前相关文件和 Git 状态。
3. 只有发生规则冲突、跨主题历史审计、检索不足以确认现状，或使用者明确要求时，才完整读取 `conversation-synthesis.md`。
4. 当前使用者最新明确要求优先，其次是现行 `AGENTS.md`，再其次是项目文档和较早历史。资源数量、路径、白名单和启用状态始终以当前工作区为准。
5. 每轮结束仍须把请求、结果、标准变化、工程变更、验证和阻塞简洁回写到 `conversation-synthesis.md`；如果形成新的长期规则或活动阻塞，还要同步更新本文件。回写失败则本轮为 `BLOCKED`。

## 风险分级验收

风险按实际影响范围判断，不能为了省时主动降级；使用者可随时要求提高等级或完整验收。

### L：低风险

- 适用：不改变节点结构、数据、交互、图片或动画的文案、颜色、间距、静态样式和小范围参数调整。
- 至少验证 `1–2` 个直接相关且有意义的真实操作或状态。
- 迭代期只跑专项检查，完成前集中做一次最终验证。

### M：中风险

- 适用：布局变化、交互行为、UI Presenter/Controller 的局部表现逻辑，以及可能影响相邻状态但不跨越 Session/数据契约边界的修改。
- 至少验证 `3` 个真实操作：目标流程、一个相邻状态、一个回归状态。
- 迭代期跑专项检查，完成前集中做一次最终验证。

### H：高风险与正式交付

- 适用：图片或其他美术资源、动画、节点增删改名移动或重新挂载、PSD 转换、Scene 路由、应用装配、Session/Core/Data/公共契约、批量修改、正式交付，以及使用者明确要求完整验收的任务。
- 至少验证 `5` 个不同且有意义的真实操作，并执行受影响范围内的完整门禁。
- 节点结构整理即使预期视觉不变，也属于 H 级。

## 截图和像素比较

- 只为本风险等级选定的操作保存同条件的 `before` / `after`；修改前漏截时，仍须从修改前提交或可靠备份补拍。
- 结构整理或明确要求视觉不变的修改，所选操作必须整图差异像素为 `0`。
- 有意改变视觉时，开工前声明预期变化区域；允许该区域出现差异，但预期不变区域必须为 `0` 差异，或用等价的边界化证据证明差异没有外溢。不得因预期内像素变化把已完成任务误报为 `BLOCKED`。
- 涉及布局、交互或动画时，必须在真实 Godot 窗口验证；headless 结果不能替代可见验收。

## 测试调度

- 迭代期间优先运行直接相关的专项 smoke、静态检查和真实入口操作；互不依赖的只读检查可并行，固定动画相位后再截图。
- `verify_ui_mirror.sh` 在相关 Scene、prefab、脚本、图片或 manifest 修改的最终阶段运行一次；纯文档流程修改不要求运行。
- README 全量 Mock smoke 仅在 H 级、正式交付，或修改应用装配、路由、Session/Core/Data/公共契约时运行一次；L 级不运行，M 级只有影响上述职责时才运行。
- 对已有日期和完整失败签名、且当前修改不可能影响其职责的全量失败，可以引用最新证据而不重复等待。失败签名改变、修改触及其职责、H 级或正式交付时仍须运行一次并如实记录。
- 本任务启动且超时不退出的进程按精确 PID 结束；不结束用户或其他任务的进程。

## 长期边界速查

- 本项目是可离线独立运行的 Godot UI/美术 Mock，不是正式玩法、存档、战斗规则或策划数值真相源。
- Runtime 数据只由 `session/mock_game_session.gd` 从 `data/mock_battle_snapshot.json` 提供；正式契约变化由项目方重新导出。
- `.tscn` 保存可编辑静态结构；复杂美术层级不得在代码中重画。节点结构变更必须先取得使用者确认。
- 后续新制或修订的精灵待机以角翼龙 `SPR_014` 为局部动作锚点：固定主体躯干、身体中心、外轮廓、脚底、脸部和全部五官，只让翅膀、耳梢、尾梢、羽毛、手指等局部部位小幅运动；局部动作必须在项目实际显示尺寸下肉眼可读，只有 `1–2px` 技术差异但看起来静止仍不合格；活动附肢必须从真实关节或根部开始连续运动，不得把根部静态覆盖后只动外端；前景活动附肢的合成顺序固定为“静态身体 → 完整动态附肢 → 仅必要的固定五官”，不得用大块静态脸/身体层压住动态根部；禁止眨眼、动嘴、表情变化，以及整只拉伸、压缩、缩放、弹跳、摆动或全身呼吸形变。
- 图片、动画、PSD、正式资源准入和真实界面验收继续执行 `AGENTS.md` 的专项严格规则；快速模式不降低这些门禁。
- 使用者已授权后续 Rika AI 在任务范围内直接调用，不再逐次确认；每次提交前仍须重读用户环境密钥、免费鉴权查余额，调用后报告实际次数和消耗。其他生成或渲染服务同样可在任务范围内直接执行。
